#  California Housing SQL Queries

This project explores the **California Housing Dataset** using **SQL queries** on cleaned data stored in a **SQLite** database.

##  Data Cleaning  
The data was cleaned in a [previous repository](https://github.com/Reham-f1/California-Housing-Data-Analysis.git).  
This repo focuses on **writing SQL queries** on the cleaned dataset (`CLEANDhousing.csv`).

##  Features
- Load cleaned data into a SQLite database using Pandas
- Run SQL queries via Python
- Analyze:
  - House prices by region, age, population, and room count
  - Grouping using `GROUP BY`, `NTILE`, and custom bins

## 🛠 Tools Used
- Python
- SQLite
- Pandas
- Google Colab
